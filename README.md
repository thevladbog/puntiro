# Puntiro Design System Platform

Puntiro Design System Platform is the workspace for Puntiro's shared interface foundation and Storybook documentation.

## Prerequisites

- Node 24
- pnpm 11.17.0

## Getting started

```bash
pnpm install
pnpm storybook
pnpm storybook:build
```

Task 14 expands this README with the complete validation matrix.
